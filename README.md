# Calculator

A simple web-based calculator built with HTML, CSS, and JavaScript.

## Live Demo

Use the calculator here: [https://niko2901.github.io/Calculator.github.io/](https://niko2901.github.io/Calculator.github.io/)

## Features

- Basic arithmetic operations: addition, subtraction, multiplication, and division
- Modulus operation support
- Clear and backspace controls
- Computation history panel with clear history option
- Responsive layout for portrait orientation

## Tech Stack

- HTML
- CSS
- JavaScript
- [Math.js](https://mathjs.org/) for expression evaluation
